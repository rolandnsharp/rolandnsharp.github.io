# SSH Into a Tarot Reading

Open your terminal and type:

```
ssh tarot.rolandsharp.com
```

That's it. No install, no signup, no browser. You'll get a three-card spread with pixel art cards, a shuffling animation, and an AI-generated reading — all rendered in your terminal with 24-bit color.

## What is this?

It's a tarot reading app built entirely in Go, served over SSH using the [Charm](https://charm.sh) stack. When you connect, you get a full terminal UI: a text input for your question, a card shuffle animation, and three cards drawn from a 78-card deck with original pixel art.

The cards are 24x40 pixel images generated with Stable Diffusion, stored as hex color values, and rendered using Unicode half-block characters (▀▄) with true color ANSI escapes. Each card has a hand-tuned border, and the deck comes with its own procedural ambient soundtrack — though you'll only hear that if you run it locally.

## How it works

The app is built on [Bubble Tea](https://github.com/charmbracelet/bubbletea) for the TUI and [Wish](https://github.com/charmbracelet/wish) for the SSH server. Each SSH connection gets its own independent session with its own shuffled deck and reading.

The card art was generated with SDXL-Turbo at 512x768 and downscaled to 24x40 pixels. At that resolution, you need a style that reads well as blocky pixel art — we landed on a neon aesthetic with electric cyan, magenta, and green on pure black. High contrast and bold shapes survive the downscale better than anything painterly.

The readings are generated by a local LLM (Qwen 0.6B via Ollama), streamed word-by-word with a typewriter effect. Each deck has its own personality prompt — the neon deck reads like "a midnight oracle in a retro arcade, speaking in sharp neon flashes of insight."

## Try it

```
ssh tarot.rolandsharp.com
```

Your terminal needs to support 24-bit color (most modern terminals do). The source is on [GitHub](https://github.com/rolandnsharp/tarot).
